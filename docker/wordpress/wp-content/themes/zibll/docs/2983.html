一个现代化WordPress网站，移动端体验才是最重要的开发方向。相信使用过子比主题的用户都知道，zibll子比主题一直都十分注重移动端的功能开发和用户交互体验，我们希望通过一款主题，让您的网站拥有堪比优质APP的移动端体验，强大而又丝丝顺滑！

功能介绍

首先我们简单的介绍一个移动端底部TAB的功能以及特色
移动端底部TAB也就是显示在手机上，页面底部的按钮，让手机端更加方便操作和跳转

  • 按钮数量随意添加、删除、排序
  • 每个按钮支持自定义图标、自定义文字、自定义尺寸
  • 主题预置了漂亮的多彩SVG图标
  • 按钮支持添加标签显示
  • 文章页、帖子页支持自动显示文章功能按钮
  • 支持页面滚动时隐藏功能
  • 漂亮的UI设计，颜色、背景、间距、尺寸都精心设计
  • 细节完美！例如：适配所有手机，不会被全屏手机的底部横条遮挡
  • 首页按钮支持自动切换为返回顶部按钮
  • 消息按钮支持自动显示未读消息数量
  • 添加按钮支持投稿、发帖、创建板块、创建话题
  • 文章内容页面自动显示当前内容的评论、点赞、收藏、评分、分享、购买按钮

功能设置

进入主题设置->全局&功能->手机底部TAB

在这里你可以开启此功能、添加按钮、根据需要设置功能

当我们添加一个按钮的时候，我们可以选择默认图标，或者自定义图标，也可以添加文章或徽章。不同的按钮类型有不同的功能
