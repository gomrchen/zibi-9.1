zibll子比主题V6用户等级功能详解及使用教程[V6新功能]

来源：https://www.zibll.com/2976.html · 离线镜像

使用WordPress建站的站长，提高网站用户的粘性，用户等级系统是必不可少的！通过用户等级划分，可以有效的提交用户活跃度、趣味性，同时提高网站的互动性，提升网站流量。

zibll子比主题V6就带来了全新用户等级系统，搭配V6全新的用户权限管理系统，站长可以根据不同的用户等级，设置不同的用户权限，将一些权限限制给高等级的用户使用，也可以有效的提交网站内容输出效率。
特别是是V6全新的论坛系统，创建板块、发布帖子、发布提问等互动性极强的功能与用户等级功能配合，能实现精细化全权限管理，方便站长管理高质量的内容输出。

此功能需zibll子比主题V6及以上版本

特色介绍

首先，我们还是简单的介绍一下用户等级功能以及它的一些特色：

  • 独立功能，一键开启或关闭
  • 支持自定义设置等级级数(例如:我的网站最高等级为10级，你也可以设置成50级)
  • 每一级的名称和图标均支持自定义
  • 支持自定义每一级的升级经验值
  • 主题预置10个等级的图标(如需更高等级，需自己准备等级图标)
  • 支持自定义经验值分配
  • 支持后台手动设置用户经验值及用户等级
  • 支持精细化权限管理，精准到每一级
  • 漂亮的前台UI界面

参数设置

这个功能设置就十分简单了。
进入主题设置->用户&互动->用户等级：开启用户等级功能，设置最高等级，再根据需要设置等级名称、图标、升级经验值等

权限设置

既然有了用户等级，然后我们再配置全新的权限管理功能，就可以实现高等级特权或等级权限等功能了

以下示例：等级高于2级才能发帖，等级高于5级以及认证用户可以免审核
