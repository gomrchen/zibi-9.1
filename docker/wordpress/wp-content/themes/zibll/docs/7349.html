zibll子比主题积分功能积分消费详解及使用教程[积分]

来源：https://www.zibll.com/7349.html · 离线镜像

wordpress使用zibll子比主题可轻松的搭建一个虚拟资源商城网站，主题支持付费阅读，付费下载、付费图片、付费视频、VIP会员以及余额系统、推广分销系统、创作分成系统，这些功能相互搭配可让您的网站拥有更高的互动性，从而提高网站收入。

zibll子比主题更新V6.3之后，我们带来了全新的余额功能和积分功能，积分相当于另一种货币，可以通过做任务、签到等方式免费获得，获得的积分还可以用户网站商品的购买。余额和积分也就形成了我的资产的功能。

功能简介

首先我们还是简单的介绍一些功能特点：

  • 支持后台单独开启或关闭此功能
  • 支持配置免费获取积分的任务
  • 支持配置使用现金购买积分
  • 支持管理员手动为用户添加或扣除积分
  • 支持积分兑换会员功能(V7.4)【查看教程】
  • 支持签到获取积分【查看教程】
  • 支持卡密兑换积分(V7.4)【查看教程】
  • 支持用户之间积分转账，同时支持用户权限管理(V7.4)【查看教程】

此功能需升级zibll子比主题V6.3及以上版本

功能配置

进入主题设置->用户&功能->用户积分：开启此功能并做相关配置

管理手动添加或扣除

如果您需要手动为用户添加或扣除，您可以进入后台->用户，找到需要操作的用户，点击编辑然后进行操作

前台展示

配置完成后，就可以在用户中心看到我的资产了，同时也就可以使用积分购买积分商品了
