zibll子比主题-网址导航、友情链接页面创建教程[V8新功能]

来源：https://www.zibll.com/951.html · 离线镜像

Zibll子比主题V3.0更新之后，增加了一个“链接列表”的页面模板，通过这个模板可以创建友情链接页面，或者其他的链接列表页面。同时网址链接由后台统一管理，方便调用。

zibll更新V8.0后将原来的“链接列表”页面模板修改修改为“网址导航”页面模板，同时增加了多选分类、搜索模块、网址导航等功能。

此功能需升级zibll子比主题V8.0及以上版本！

接下来我们就一步一步的教大家创建一个网址导航页面！

管理链接

我们可以在后台统一管理链接，以及链接分类！

创建网址导航页面

  1. 首先在Wordpress后台新建页面，输入标题
  2. 在页面模板选择“Zibll-链接列表”模板，然后记得保存一下，再刷新一下页面，在下面就可以看到模板配置了
  3. 根据需要编写页面内容（或者空白）
  4. 根据需要修改页面的特色图片（也就是封面图）
  5. 选择需要显示的分类，支持多选、拖动排序，选择的分类大于1个时候，将会以网址导航的形式显示
  6. 根据需要选择是否开启搜索引擎模块，以及提交链接模块

注意事项

我们在配置页面的时候，有几点需要注意一下

  • 选择页面模板后一定要保存再刷新页面才能看到模板配置
  • 如果只选择了一个分类，则不会显示导航栏，更加适合做为友情链接等页面使用
  • 支持三种风格显示，根据自己喜欢选择
  • 开启了首页引擎模块后，建议在有下面关闭页面标题显示，同时请设置一张特色图像作为背景图
  • 此页面同时支持开启小工具模块布局，如果您需要在此页面添加更多模块，可以使用小工具添加
  • 在任何页面都可以使用模块配置的方式添加链接列表模块，支持4种样式，使用更自由【查看教程】
