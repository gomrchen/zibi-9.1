接入百度API内容审核并开启免人工审核功能详细教程[V6新功能]

来源：https://www.zibll.com/2997.html · 离线镜像

做网站审核内容一直是比较消耗精力的事情，例如评论审核，投稿审核等等。使用zibll子比主题搭建的WordPress网站，有拥有很多的交互功能，特别是更新V6之后，又增加了全新的论坛系统，随着网站用户增多，那需要审核的内容也就越来越多了，全部依靠人工审核，那可就有的忙了！这时候zibll子比主题的API智能内容审核功能就能大显身手了！

通过接入百度内容审核，实现网站所有用户提交内容进行api审核，极大的简化人工审核流程！如果您开启了论坛系统，网站交互也比较多，那么建议开启此功能！

此功能需要zibll子比主题V6或以上版本

功能介绍

首先我们简单的介绍一下内容审核功能以及特色：

  • 支持文本审核包含：用户名、用户签名、发帖、投稿、评论、创建板块、话题等
  • 支持前台所有的图片上传审核
  • 配合用户权限功能，可实现免人工审核功能(api审核通过后直接发布)
  • 前台AJAX方式审核，响应更快且不影响页面加载速度
  • 各个功能是否审核可独立开关

由于不同厂商接入方式以及返回方式都有较大的差异，很难统一接口，所以主题暂时仅接入了百度内容审核，后期可能会继续添加其它接口

百度API审核特点：

  • 价格便宜，首次使用还能免费领取5万次文本，1万次图片审核(21年12月)
  • 自带全面的审核库，内容匹配精准
  • 支持自定义审核策略，配置灵活且简单易用

百度内容审核接入教程

接下来我们一步一步的申请并接入百度内容审核

注册并登录

首先进入https://ai.baidu.com/solution/censoring，注册并登录

登录后点击立即使用

创建应用

点击创建应用

再次点击创建应用，先免费领取审核次数

然后根据需求填写好相对应的需求点击立刻创建

获取App Key和Secret Key

应用创建完成之后，我们就可以开始使用了，进入应用详情，复制App Key和Secret Key

主题设置

进入主题设置->扩展功能->api内容审核：将刚刚获取的App Key和Secret Key保存到主题设置中

然后根据需要，开启需要审核的功能

免人工审核设置

接入API审核并开启之后，如果用户在提交的时候有违禁词会直接提示错误。如果需要api审核通过后就直接发布，那么请在用户权限中开启免人工审核功能。

注意事项

  • 此功能仅对前台操作有效，wp后台操作不审核
  • 此功能不会审核管理员操作的内容
  • 此功能不会在前台显示接入错误信息，前台使用时只有接入成功并且返回不合规时候才会向用户提示。所以此功能配置完成后请在主题设置最下方进行测试
  • 此功能需要连接API接口，需要额外耗费一定时间，为了避免出现长时间无响应，此功能最长响应时间为12秒，如果您的服务器网络很慢，可能会无法正确审核
  • 百度api的默认规则不一定适合每一个网站，如果出现了误报，请自行调整策略
  • 建议关闭违禁词的模糊匹配，开启后会很容易误报，如图所示
