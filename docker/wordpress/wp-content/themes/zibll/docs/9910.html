社区论坛首页的板块分区以及板块排序修改教程

来源：https://www.zibll.com/9910.html · 离线镜像

这个问题最近问的比较多，如何修改论坛首页的板块分区以及板块的显示顺序？

事实上我们在设置论坛首页的栏目的时候就可以设置了。论坛首页栏目的设置方式可以查看以下文章：

zibll子比主题论坛板块页面配置及Tab栏目配置教程
1个月前
1.1W+13

回到主题，我们来设置板块的排序方式：

进入主题设置->社区&论坛->首页设置：展开板块列表设置，找到板块分区和板块的排序方式设置，根据需要设置即可

教程结束，主要注意的是板块分区支持手动排序，如果选择了手动排序，那么未添加的分区就不会显示！

板块不支持手动排序，但支持很多种的排序方式，完全够用啦！
