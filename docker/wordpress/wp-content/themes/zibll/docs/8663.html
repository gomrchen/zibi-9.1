zibll子比主题卡密充值、卡密兑换积分、卡密兑换会员功能详解及使用教程[V6.5新功能]

来源：https://www.zibll.com/8663.html · 离线镜像

有一些老站长可能会卡密充值的功能了解比较多，使用wordpress建站的站长很多时候不方便接入收款方式，但是有需要销售商品，这时候就可以通过卡密充值的方式充值到余额，然后用户就可以通过余额购买商品了。
同时卡密功能可以用于其他的一些用户活动，例如把赠送卡密给客户等等。

zibll子比主题V6.5更新就带来了全新的卡密充值功能，首先我们简单的介绍一下。

此功能需升级zibll子比主题V6.5及以上版本

zibll子比主题更新V7.4后，新增卡密兑换会员、卡密兑换积分的功能，使用教程和此教程类似
更新V8.3后，新增自定义卡密功能，方便配合商城系统实现自动发卡

功能简介

  • 精美设计的UI，简单漂亮
  • 支持单独开启或关闭，支持自定义说明简介
  • 支持批量移动生成卡密
  • 支持批量导入卡密
  • 支持导出卡密为Excel文档或txt文档
  • 支持卡密充值余额、卡密兑换会员、卡密兑换积分(v7.4)
  • 卡密充值余额支持设置单密码模式，不需要卡号(v7.4)
  • 支持自定义卡密创建和导入，方便配合商城系统实现自动发卡（V8.3）

截图预览

配置教程

进入主题设置->付费商城->余额充值：开启卡密充值余额功能

进入主题设置->用户互动->用户积分：开启卡密兑换积分功能

进入主题设置->付费商城->VIP会员：开启卡密兑换会员功能

卡密管理

进入zibll商城->充值管理，即可看到卡密列表，支持批量删除。以及导入导出

导入卡密

点击添加卡密，可选择自动生成卡密或导入卡密

导出卡密

如果您需要将卡密放在其他平台进行销售，或有其他用途，都可以导出卡密
