zibll子比主题商城物流跟踪-快递查询接口配置教程[V8.2新功能]

来源：https://www.zibll.com/39206.html · 离线镜像

zibll子比主题更新V8.2之后，新增了实物商城功能，现在可以使用zibll主题搭建独立的WordPress商城网站了！

既然是实物商城，那肯定少不了物流跟踪功能，例如发货、退货，所以我们需要配置好快递查询接口

配置教程

进入后台->主题设置->商城&商品->物流&发货：配置快递查询接口、以及接口参数等其它功能

关于查询快递查询间隔时间设置，需要注意的是：主题并不会在后台查询快递信息，而是当用户或管理员点击查看快递信息时，才会通过API接口进行查询。这里配置的间隔时间，实际上是API查询的最小时间间隔，也就是说在此间隔时间内，用户或管理员查看同一快递信息，都不会通过API更新内容

快递鸟接口

快递鸟是国内知名的物流信息服务商，价格实惠，支持免费试用。

配置方法：注册并登录后，进入快递鸟后台-账号管理-API密钥管理，将获取到的用户ID和API KEY填入主题配置即可

快递100接口

快递100也是常用的快递接口，支持免费试用。

注册并登录后，进入快递100后台，将授权key和customer填入主题配置即可。

阿里云接口

阿里云全球快递物流查询支持30天100次免费试用

先进入全球快递物流查询页面，免费领取试用或购买后，进入云市场控制台，就可以看到AppCode了，只需要把AppCode填写到主题配置中即可

后台测试

参数填写完成后记得先保存主题配置！然后就可以找一个订单号，自己先测试一下
