php安装扩展教程-解决网站提醒缺少mbstring组件的错误

来源：https://www.zibll.com/47062.html · 离线镜像

这个教程本来不应该存在的，但是由于PHP 在某个版本之后（貌似是8.0开始）默认居然不自带mbstring组件了，这可是十分基础的文字处理组件啊，经常要用到。

缺少mbstring组件，网站后台会有提醒，没有这个提醒就说明自带已经安装好了，就不要再安装了

教程十分简单，进入宝塔，点击PHP设置-点击安装扩展，找到mbstring，点击安装，搞定

需要注意的是，如果你安装了多个不同版本的PHP，最好都安装一下，至少要把你在用的版本的php给装了

同样的，如果需要安装其他组件，方法也一样。

最后，这几个组件建议都要安装：

  • opcache 强烈推荐安装，提升性能的核心组件
  • fileinfo，imagemagick，exif，这三个建议安装，可以提高网站上传效率
  • redis 强烈建议安装，但是这个比较占内存，4G内存可能都有点紧张，8G就完全没问题了。这是重要的缓存组件，详细使用教程请查看此教程：使用Redis和opcache为网站加速教程&浅谈快到起飞的子比主题
