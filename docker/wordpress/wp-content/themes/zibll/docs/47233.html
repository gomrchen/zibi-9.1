zibll子比主题智能多语言翻译功能简介及配置教程[V9.0有更新]

来源：https://www.zibll.com/47233.html · 离线镜像

使用WordPress做网站，往往都只能设定一种语言，但是很多时候我们可能会遇到不同国家的用户，也就是说我们需要网站同时拥有多个语言，并支持切换，zibll子比主题之前一直都是不支持其他语言的，我们也在思考如何来解决多语言问题。现在zibll子比主题V8.8推出了智能多语言翻译功能，无需人工手动翻译，配置简单，几分钟就能让您的网站支持多语言切换功能！

注意：智能多语言翻译和原生的多语言是有一定区别的。子比主题支持原生支持多语言，可以将你的网站在后台设置为英语或简体中文。子比主题默认自带两种语言包：中文和英语。你可以通过插件或其他方式通过 .POT 文件的方式来扩展其他语言包。而本文所说的智能多语言翻译功能，主要是指在前台显示多个语言的切换按钮，且不需要自己编写语言包，方便不同国家的用户可以切换到想要的语种，而不是固定使用一种语种。
zibll主题V9.0新增前后台语言分离功能，可以分开设置前台和后台的语言，例如：前台设置为英语，后台设置为中文片【查看截图】

功能简介

zibll主题智能多语言翻译功能基于 translate 开源项目，为网站提供智能翻译及多语言切换功能。用户启用后，可在网站前台轻松切换不同语言，提升国际化访问体验，适用于多语言内容展示和跨境访问需求。

主要特点：

  1. 配置简单：基于 translate 开源项目，自动识别和翻译网页内容，无需人工翻译，仅需在后台一键开启即可
  2. 翻译精准度极高：实测翻译默认翻译服务，精准度高达99%，如需更好的翻译效果还支持AI大模型翻译
  3. 响应速度极快：100毫秒即可翻译整页翻译，并自动缓存到用户本地，再次打开网站几乎0延迟翻译
  4. 自动识别并翻译：支持自动识别用户所在地区，并自动翻译，无需用户手动切换
  5. 多语言切换：支持在前台展示语言切换按钮，用户可以自由选择自己熟悉的语言。
  6. 自定义翻译：允许自定义术语词汇，确保专业内容和品牌名称不被误翻译。
  7. 多语言支持：支持中文、英文、韩文、日文、法文、德文等60+语言，基本适配所有
  8. 翻译服务可选：内置微软免费翻译服务，同时支持接入 GiteeAI 大模型翻译服务，提高翻译精度。
  9. 灵活配置：支持自动切换用户语言、本地语言设置、指定忽略翻译词汇等，满足多样化需求

配置说明

  • 切换语言列表：选择并配置前台可以切换的语言列表
  • 自动切换用户语言：首次访问网站时自动识别用户语言并切换，可选择开启或关闭。
  • 本地语言：设置默认显示的语言，例如“简体中文”。
  • 自定义翻译术语：可添加关键术语，指定翻译结果，可起到翻译修正效果
  • 自定义翻译服务接口：如果使用自建 translate 接口，可填写域名，支持多个接口。
  • 忽略翻译指定词汇：例如输入 zibll，确保该词不被翻译。
  • 翻译服务选择：可选择微软免费翻译服务，或使用 GiteeAI 大模型翻译以提高精准度。
  • 限定语种翻译：可限制只翻译指定原始语言内容，避免不必要的翻译。
  • 动画过渡效果：可选择开启或关闭翻译请求的动画过渡效果。

注意事项：

zibll智能多语言并非人工翻译，所以还是有几点需要注意的：

  • 前台切换语言列表不建议选择太多，建议根据自己网站的受众地区，仅开启常用语言即可
  • 机器翻译并不能保证100%精准，如果你发现了翻译错误的地方，可以使用自定义翻译术语功能进行修改微调
  • 由于不同语言同一段文字长度差异巨大，特别是日文、俄文等，翻译后页面UI可能会有错位现象，主题已经尽量适配了，但是极少地方可能还是会有，这个是无法完全避免的，请知晓

隐私说明

zibll智能多语言是基于translate开源项目，翻译时会把内容传到翻译接口，如果您对隐私有极高要求，建议自己私有化部署translate翻译服务，部署后将地址配置到主题设置中即可。
