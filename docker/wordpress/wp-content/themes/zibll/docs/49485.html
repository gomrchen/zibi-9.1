布局模块：幻灯片+图片视频封面组合模块配置教程[V9.0新功能]

来源：https://www.zibll.com/49485.html · 离线镜像

子比主题一直都有两个非常强大的模块：一个是幻灯片模块，另一个是图文视频封面模块。
幻灯片模块是指多张图片或视频左右滑动切换的模块；图文视频封面模块常用于单个或多个图片展示，或单个、多个视频展示。
本次zibll V9.0 更新后，新增了幻灯片 + 图文视频封面组合模块，可在单个模块上左侧放置幻灯片，右侧放置图文视频封面模块，支持自由调节左右显示的比例，以及右侧卡片的列数和行数。还支持移动端上下布局及多项配置，相当于将两个模块结合，能实现更丰富的展示效果。
