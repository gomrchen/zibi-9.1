zibll子比主题-商城系统简介-商城功能入门配置教程[V8.2新功能]

来源：https://www.zibll.com/39144.html · 离线镜像

zibll子比主题付费商品主要分为文章中的知识付费功能、论坛帖子的付费阅读，V8.2更新后，新增了独立的商城系统，支持发布任意实物商品、自动发货的虚拟商品和手动发货的虚拟商品，功能涵盖发布、优惠、便签、下单、购物车、支付、发货、物流跟踪、售后、退款、退货、评价等全流程全功能，购物体验、UI设计全面对标淘宝、京东等大厂！现在，使用WordPress和zibll子比主题就可快速、低成本的搭建完整、精美的的商城独立站了！

功能及特色简介

功能简介：

  • 商品发布：
    • 自动虚拟商品：卡密、邀请码、等任意文本内容自动发货
    • 手动发货虚拟商品：例如话费充值、游戏币充值、远程技术辅助等
    • 任意实物商品：支持物流发货、物流监控、运费配置等
    • 商品选项：不同商品规格不同价格，不同库存，不同图片等
    • 服务保障：自定义商品服务，例如7天无理由退货等服务
    • 价格类型：积分商品、现金商品
    • 商品参数：例如手机的像素、屏幕尺寸、电池容量等
    • 商品限购：按会员等级、是否认证分别设置限购数量
    • 自定义用户必留信息：例如话费充值要求用户必留手机号等
    • 自定义售后服务：是否开启退款、退货、保价等
    • 还支持配置封面图像、封面视频，支持多级分类、支持商品标签等功能
  • 优惠活动：
    • 支持立减、折扣的优惠方式
    • 支持设置时间有效期，满多少金额可享受、哪些用户类型可享受
    • 赠品：支持添加多个赠品，支持赠送站内虚拟资源(积分、会员、经验值等)或其它任意商品
    • 优惠活动可叠加、可多选
  • 其他功能
    • 支持购物车合并下单
    • 商品页面内容支持多种布局方案，支持模块化布局
    • 下单、支付、发货、物流跟踪、收货、评价、售后等流程和淘宝京东等大厂一致
    • 精美的全新后台统计、后台订单页面

特点简介

  • 配置极其简单：3分钟上手，后台配置清晰一目了然，配置逻辑简单易懂，不用看教程都会用
  • 功能强大且高度自由化：几乎商城需要的所有功能都有，并且我们首次采用配置继承功能，配置参数时高度自由化（下面教程会讲）
  • 精心打磨的UI设计：不管是PC端还是移动端，所有细节都是精心打磨，大到整体框架，小到文字颜色、间距再到UI动画都是精心处理，就是让用户享受比淘宝京东还丝滑的购物体验
  • 优雅的的购物体验：用户的购物流程和现代化商城APP完全一致，简单易用，0上手成本
  • 高性能优化：V8.2新增了约20%的代码量，但是性能反而再次翻倍提升，降低建站成本和门槛【查看优化教程及说明】
