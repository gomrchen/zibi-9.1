zibll子比主题邀请码注册功能详解及配置教程[V6.5新功能]

来源：https://www.zibll.com/8673.html · 离线镜像

使用wordpress建站的站长们，对邀请码功能需求还是很大的，邀请码注册可以有效的增加网站用户活跃度和质量。合理运用邀请码功能还可实现多种功能，也增加了网站的扩展性。

zibll子比主题的用户功能可以说十分强大了，不仅支持手机、邮件、第三方登录等功能，还拥有完善的用户管理系统，接下来那么我们老看看本次更新的邀请码功能

功能简介

  • 支持单独开启或关闭此功能
  • 支持设置为必须使用邀请码才能注册
  • 支持设置使用邀请码注册的用户可以赠送会员、积分、余额、经验值等奖励
  • 每一个邀请码都可以单独定义奖励方式
  • 支持批量自动创建邀请码
  • 支持批量导入邀请码
  • 支持导出卡密为Excel文档或txt文档
  • 支持商城系统直接销售邀请码，且支持自动发卡。（V8.2）【查看教程】

预览截图

配置教程

进入主题设置->用户功能->登录注册：开启邀请码注册

邀请码管理

进入用户->邀请码管理：即可查看邀请码列表，也可以添加或导出邀请码

创建邀请码

点击添加邀请码，可以选择自动生成邀请码，或导入邀请码。同时可以配置邀请码的使用奖励

导出邀请码

点击导出邀请码，即可导出为Excel文档或txt文档
