在线更新教程、升级教程、常见问题解答[优雅的升级体验]

来源：https://www.zibll.com/1411.html · 离线镜像

使用Wordpress的朋友可能都有这样的同感：功能强大，但是太麻烦了….

如果你已经看了V5的更新日志，可能你就会发现，在很多细节上子比主题都在思考着如何让站长更方便，让主题使用更容易！我觉得这个很重要！

当您使用子比主题V5之后，那么今后就再也不用繁琐的上传主题、替换文件来更新主题了！

一键在线更新，优雅的升级体验

  • 主题默认会每周自动检测一次更新，如果有更新会在后台显示有更新的通知
  • 当然你懒得更新，也可点击忽略此次更新
  • 后台一键在线更新，30秒左右即可完成主题升级
  • 不用担心更新服务器像wp一样连接不上，子比主题每一版都会有3个以上不同下载服务器，一个下载失败自动切换另一个
  • 更新过程显示进度条，告别枯燥的等待过程

常见问题解答

在线更新在使用的过程中，可能会因为一些环境不同，而导致失败，如果在线更新失败，您仍然可以通过下载安装包手动更新！
在这里我们汇总一些常见的错误及解决方案，如果您也出现了类似的问题，也许能帮到您！

如果您出现了此处未提及的错误，欢迎您在下方留言！我们第一时间帮助您解决问题

为什么官网已经发布新版，而我的后台没有显示有更新呢？

系统自动检测更新频率为一周一次，可能是官网发布更新时，还未到触发您的自动检测。
您可以在主题设置-文档更新：点击检测更新以手动检测新版更新。

为什么我后台提示的更新版本和官网发布的不一致呢？

可能是由于您长时间未登录后台或者其它时间差导致的版本不一致
您可以在主题设置-文档更新：先忽略此次更新->在点击检测更新，以同步最新可更新版本

主题显示更新成功，刷新页面之后怎么还是之前的版本呢？

有些站长为了一些功能可能会修改部分主题源文件。那么需要注意的时，主题路径文件夹和主题信息文件是不能修改的，否则会出现因信息判断出错，而导致的失败！

在线更新的时候，下载了一半，就报错错误，是什么原因？

这种情况是最常见的，大多数都是因为用了CDN导致的，因为所有的CDN都会限制源站响应时间，一般是10-30秒，然而更新主题需要50-80秒的时间，所以就会出现源站响应超时的错误，一般会出现5xx或0的错误码。

解决此问题，大致有三种方式：

  1. 少部分CDN支持设置源站超时时间(部分CDN服务商叫法可能不同)，那么可以将此时间设置为70秒以上【查看截图示例】
  2. 通过修改自己电脑的hosts文件，指定网站不通过CDN直接访问源IP，这种方式设置好之后记得PING一下自己的网站，等hosts文件生效后，再重启浏览器后再更新【查看截图示例】【百度教程】
  3. 最后就是临时关闭CDN，将域名解析到源站，这种方式最不推荐，麻烦且不安全，还不如手动更新

最后有一个小细节需要注意，记得检查php设置的最长运行时间，最少70秒以上

为什么明明发布了新版，但是我点击检测更新仍然提醒没有更新呢？

刚发布新版的时候可能会出现大量用户检测更新，这时候可能会因为网络拥堵而导致未检测成功，如果多次检测都没有，就建议手动更新或者等一段时间再试试哦

更新成功后页面显示白屏或者显示一行英文报错怎么回事？

这是由于更新主题会替换核心文件，有时候页面会来不及重新渲染，稍等几秒重新刷新页面即可

还有没有其它可能的原因导致在线更新失败呢？
  1. 部分插件可能会有冲突或者保护机制，所以禁用插件排除一下是不是插件冲突
  2. 网络问题，有时候网络太慢，或者有些国外服务器可能会出现此情况
  3. 文件/文件夹权限问题导致更新文件写入失败！请确保权限和所有者都正常【查看权限错误示例】
  4. 部分cdn、或者防火墙可能会屏蔽或拦截

最后，如果您还是不能使用在线更新，那就只有手动更新了，也十分简单哦！
