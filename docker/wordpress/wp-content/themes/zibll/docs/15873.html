zibll子比主题评论和用户主页显示IP归属地功能配置教程[V7.2新功能]

来源：https://www.zibll.com/15873.html · 离线镜像

使用wordpress搭建网站的站长们估计已经对这个功能很熟悉了，包括现在主流的软件都有显示ip归属地的功能了，使用zibll子比主题，仅需简单两步即可实现评论显示ip归属地以及用户中心显示用户ip归属地。

使用此功能需升级zibll子比主题V7.2及以上版本

截图示例

配置教程

这个功能的配置就十分简单了，仅需在主题设置开启此功能即可。

同时主题自带了免费的太平洋公共查询接口，但是免费的公共接口可靠性不太高，那么子比主题还接入了腾讯和高德接口，相对更为可靠！

同时主题支持多接口轮流查询，一个接口未查询到地址，自动切换另一个接口进行查询，再次提高了可靠性！

首先我们进入主题设置，开启对应的显示：

完成以上操作以后，就直接可以使用此功能了，但是以下几点需要注意一下：

  • 如果您的服务器使用了代理功能，主题已做针对性优化，也能正常获取IP。但是，如果是本地局域网搭建，则无法获取IP，并且也有部分用户可能会通过某些技术手段来隐藏IP，那么也可能无法正确的获取IP，故此功能并非100%可靠
  • 同理，因为是需要通过接口查询IP归属地址，接口查询也无法做到100%可靠，推荐同事使用腾讯和高德的接口，并使用轮询查询功能，可靠性更高
  • 重要提醒：评论显示IP归属地，是在用户评论的时候进行获取，所以已评论的内容不会再显示
  • 用户显示IP归属地，是在用户登录的时候进行获取，已注册的用户需要下一次登录的时候才会显示

接口配置

上面我们已经说过了，主题自带免费的查询接口，无需任何配置即可使用，但是如果您需要更可靠的使用，我们建议自己申请腾讯或者高德的接口进行使用。

首先我们进入主题设置，选择我们需要使用的接口，并把相应的接口参数填上即可：
