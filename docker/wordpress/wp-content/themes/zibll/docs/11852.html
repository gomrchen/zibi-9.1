社区论坛设置帖子视频封面、图集封面功能介绍及配置教程[V6.9新功能]

来源：https://www.zibll.com/11852.html · 离线镜像

一个现代化的社区论坛，显示ui必须符合现代化程序。子比主题更新V6.9之后又带来了全新的帖子封面功能。支持视频、图集封面，支持在列表直接显示、自动播放，这下再次提高了网站的交互体验，同时也更加符合现代化程序设计了。

重要通知：由于政策原因，官网下架了论坛功能演示，如需查看zibll主题论坛相关功能演示，请跳转到到：www.zibll.top

特点介绍：

首先我们简单的介绍一下这个功能的几个特点：

  • 支持视频封面、图集幻灯片封面、图片封面
  • 这几种封面均支持单独设置显示的长宽比例，以统一显示风格
  • 视频封面支持在列表中自动播放（同时支持后台开关此功能）
  • 支持用户权限管理系统，可以细分的设置哪些类型的用户可以使用此功能
  • 简约美观的UI设计也更加符合现代化程序，有效的提高了网站的用户体验

配置教程

得益于子比主题强大的用户管理系统，所以这个功能的配置就十分简单了，仅需简单一步即可完成配置。

如果您还未了解过子比主题的用户管理系统，强烈建议先查看以下教程：

zibll子比主题用户权限管理系统简介及教程[V6新功能]
6个月前
2W+72

教程开始：

进入主题设置->权限功能->论坛帖子权限：找到以下三项，根据您的需要为对应用户开启权限即可。

配置完成，拥有此权限的用户在发帖的时候就可以设置封面了。

注意事项

我们有两点需要注意一下：

  1. 开启此功能会允许用户上传对应内容，请注意设置用户允许的图片和视频的上传大小。
  2. 上传视频比较占用服务器性能的，所以视频封面功能请酌情开启
