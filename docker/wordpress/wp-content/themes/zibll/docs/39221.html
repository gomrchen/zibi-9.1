zibll子比主题v8.2更新的商城系统，满足各种类型商商城网站，支持发布任意商品，包括所有实物商品，自动发货的虚拟商品和手动发货的虚拟商品，那么同时，不同类型的商品对详情页的UI布局可能也有不同的需求。因此主题也适配了多种效果，满足几乎所有类型的商品显示。

内容区域布局配置

重点我们说的就是内容区域的布局配置，这直接影响到商品详情显示的UI效果，必须要根据自己商品的情况合理设置，才能达到最好的效果。

配置方法

首选我们看一下，需要配置的几个重点参数和功能：

  1. 商品详情而布局：全屏、适应内容宽度、适应内容宽度+侧边栏
  2. 商品详情背景盒子：显示、隐藏
  3. 古腾堡块：无缝图块

配置示例

那么我们根据常见的不同商品类型，举几个例子来展示一下这几种功能配置后的布局效果

1.最常见的实物商品，例如手机、服饰、家电等，目前淘宝京东拼多多等商城最常见的做法就是商品详情介绍全部都是图片拼接，并且全屏展示，效果最佳。
那么我么这样配置：1.商品详情页布局选择全屏，2.商品详情背景盒子选择隐藏，3.所有商品介绍只是用无缝图插入图片（无缝图开启宽度填满容器）。最终效果如下：

2.有时候我们的商品介绍并不是全是图片填满，可能就是常规的图文融合，因为一般也只有知名产品、或者大公司才能为自己的产品做全图介绍，那么像这种图片文字都有的详情介绍，使用全屏显示效果就不好看了。那么我们这样配置：1.商品详情页布局选择内容适配宽度，2.商品详情背景盒子选择显示，3.商品介绍就正常编辑。最终效果如下：

3.很多站长可能不会销售比较知名的品牌产品，例如技术服务、自动发卡等，没有专业的图片介绍，同时还可能需要显示丰富的内容，那么这时候我们可以开启侧边栏（注意：侧边栏不会在移动端显示），整体效果如下：
