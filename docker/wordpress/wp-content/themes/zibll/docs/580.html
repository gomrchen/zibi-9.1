功能配置

进入后台：主题配置->支付&付费->知识付费，在这里我们配置常用功能，例如：收费模块显示位置，免登陆购买等功能

创建付费内容

我们在后台编辑文章时候，在最底部即可看到付费功能相关配置：

在这里，我们可以看到全部配置选项，可以依次配置付费模式、购买权限、支付类型、价格及商品信息等功能，同时有几点需要注意：

  • 执行价设置为0，则为免费商品
  • 如果需要配置仅会员可购买，请将执行价设置为大于0的金额
  • 付费阅读必须配合隐藏模块使用，详见下方教程

付费阅读

  1. 勾选付费模式为付费阅读
  2. 设置付费价格以及其它信息(非必填项可以不用填)
  3. 在文章中插入 付费隐藏内容

使用古腾堡编辑器插入付费阅读内容

推荐使用古腾堡编辑器插入，选择 隐藏内容（新版） 模块，并将隐藏模式设置为：付费阅读

付费图片

  1. 勾选付费模式为付费图片
  2. 添加付费图片资源，设置免费查看数量

付费视频

  1. 勾选付费模式为付费视频
  2. 添加付费图片资源，设置免费查看数量

其它设置

销量浮动： 为真实销量增加或减少的数量

标题：可选项，单独设置付费内容的标题，支持HTML代码，默认显示当前文章为标题

简介：可选项，单独设置付费内容的简介，支持HTML代码，默认显示付费类型的介绍

更多详情：可选项，显示在付费卡片下方的内容，可插入版权信息、下载提示等内容，支持HTML代码

额外隐藏内容：可选项，购买后显示在付费卡片下方的内容，可插入解压密码等隐藏内容，支持HTML代码

建议：以上可选项均可使用HTML代码，如果您你懂HTML代码，可以直接填文字就行，留空效果也佳

前台配置

如您需要开放设置付费功能给其他用户，也就是让其他用户在前台发布文章时，也能设置付费内容。

那么您可以使用zibll子比主题权限管理系统，配置哪些用户可以使用此功能。

进入后台：主题配置-功能&权限-基本权限：进行配置

配置完成后，拥有权限的用户就可以在前台设置付费内容了
