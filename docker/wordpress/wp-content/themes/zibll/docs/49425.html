当我们搭建好了一个 WordPress 网站，网站中可能会存在文章、帖子、商品等多种不同类型的内容，很多时候我们也需要将这些内容分享到其他社交平台上，例如 QQ、微博、QQ 空间或者 Twitter X 等。子比主题自带了国内外常见的社交分享平台，可以一键快速地将内容分享到这些平台上。

目前支持的分享渠道：微博 QQ好友 QQ空间 Facebook X(Twitter) Telegram WhatsApp LinkedIn Reddit LINE VK 邮件 海报分享 复制链接

配置方式

所有的分享渠道都支持开启、关闭以及排序。我们一般建议，国内的网站开通国内常见的分享渠道，海外网站则开启海外的相关分享渠道，不建议全部开启，根据自己网站的类型按需开启即可。

微信分享

微信分享可能是大家问到最多的问题，大家都在问为什么没有分享到微信的按钮，以及为什么分享到微信没有图片等问题。因为微信是不支持用一个按钮进行分享，只能调用微信 APP 内右上角自带的分享按钮，并且微信分享也有严格的限制，必须要有已认证的公众号才可以使用，具体使用方法请查看以下教程：
