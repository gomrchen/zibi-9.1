作为论坛的两个基本功能：发布和查看。
发布包含：创建板块、创建话题、发布帖子等
查看主要为查看帖子的内容

学会了发布限制之后，我们还需要考虑一个问题，如何设置哪些人允许查看哪些内容呢？
接下来的教程，我们熟悉板块查看限制和帖子阅读限制这两个功能的配置！

支持设置为：

  • 登录后即可查看
  • 评论后可查看
  • 达到某个等级后可查看
  • 开通某个等级的会员后可查看
  • 认证用户可查看

板块查看限制

板块查看限制，顾名思义就是将板块设置为限制查看后，拥有权限的用户才能查看到该板块的帖子内容，没有权限的无法查看

配置教程主要为两个部分：
1、配置哪些用户可以设置此功能
2、配置板块的查看限制功能

首先进入主题设置->功能&权限->论坛权限：找到设置板块查看权限的功能，按照需要设置用户组

设置好这一步之后，那么拥有此权限的用户，就可以在对应的板块设置该板块的查看权限了！

帖子查看限制

板块查看限制是将整个板块的所有帖子都进行限制查看，当然我们肯定也需要将某一篇帖子单独设置查看限制

同样的配置教程主要为两个部分：
1、配置哪些用户可以设置此功能
2、配置板块的查看限制功能

首先进入主题设置->功能&权限->论坛权限：找到设置帖子查看权限的功能，按照需要设置用户组

设置好之后，拥有权限的用户就可以在发帖或者帖子管理中单独设置该帖子的查看权限了
