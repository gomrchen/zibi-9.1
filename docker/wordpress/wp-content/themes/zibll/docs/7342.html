zibll子比主题余额充值余额消费详解及配置教程[余额]

来源：https://www.zibll.com/7342.html · 离线镜像

作为一款深受喜爱的wordpress商城主题，zibll子比主题拥有丰富的虚拟商城功能，例如付费阅读、VIP会员、付费论坛、分销推广、创作分成、积分系统等，这一次升级V6.3以后我们又更新了余额系统，极大的增加了网站付费功能的扩展性。

余额功能包含余额充值、余额消费以及余额提现，它与创作分成和推广返佣功能相互关联，接下来我们就详细的介绍一下此功能。

功能简介

余额功能可以说是网站的另一种货币，我们先简单说说此功能的特点

  • 后台支持单独开关此功能
  • 支持单独设置充值金额以及充值折扣
  • 支持设置是否允许用户手动属于充值金额
  • 支持设置是否允许余额提现
  • 支持管理员在后台手动为用户添加或扣除余额
  • 支持卡密充值余额（V7.4）
  • 支持用户之间余额转账（V7.4）【查看教程】

此功能需升级zibll子比主题V6.3及以上版本

配置教程

进入主题设置->付费&商城->余额功能：开启此功能并做相关配置

同时我们可以添加一些商品选项，并合理的设置一些折扣，更加有利于用户消费

管理手动添加或扣除

如果您需要手动为用户添加或扣除，您可以进入后台->用户，找到需要操作的用户，点击编辑然后进行操作

前台展示

后台配置完成之后，用户就可以用户中心看到我的资产了，同时前台购买商品也就可以使用余额支付了
