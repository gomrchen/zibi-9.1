zibll子比主题按分类限制文章查看权限配置教程[V8.8新功能]

来源：https://www.zibll.com/47325.html · 离线镜像

zibll主题有十分强大的用户权限管理系统，同时也支持多种多样的隐藏内容功能，例如隐藏部分内容，会员可见、付费可见等，zibll更新V8.8之后，又带来了按照分类来设置文章查看权限的功能！

顾名思义，在某一个分类中开启阅读权限后，此分类下的所有文章都需要满足配置的要求才能查看！

配置教程

配置的教程十分简单，在后台-文章-分类目录中，找到你需要开启阅读权限的分类，点击编辑，开启文章阅读限制，并按需配置即可：

支持配置为登录后可见，或者按照用户角色限制：包含用户等级、会员等级、是否认证

注意事项

  • 分类的阅读权限和文章的隐藏内容是同时存在的，请注意合理搭配。
  • 此配置支持继承，也就是说开启了阅读限制的分类，它下面的子分类及时没有开启也会按照相同配置进行限制！但是如果子分类开启了，则最小的子分类优先
  • 同一个文章如果有多个分类，则只要有一个分类开启了阅读限制，则都限制
