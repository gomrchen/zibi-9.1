丝丝顺滑的图片浏览体验-图片灯箱功能详解

来源：https://www.zibll.com/683.html · 离线镜像

使用wordpress建图片站的站长可以说非常多的，zibll子比主题是一款多功能的阅读类主题，说到阅读，那肯定少不了图片。如何让图片布局灵活、漂亮！又如何让用户易于图片浏览、图片操作，这些都是子比主题重要的开发项目，越是看似简单的时候，我们越会做的认真。

首先主题才用模块化布局，同时文章也基于wordpress的古腾堡编辑器才用模块化编辑文章，那么使用子比主题就能很轻松的用模块的方式将图片添加到您的网站。

特别是在文章中插入图片，不急支持最基础的图片插入，还支持多宫格布局，图片蒙版，图片幻灯片，图片异步加载等功能，方便每一位站长简单轻松的实现漂亮的文章图片插入！
将文章中的图片布局完成之后，我们需要考虑的就是用户查看图片的体验如何？所以子比主题开发了强大的图片灯箱功能，点击图片即可弹出图片灯箱查看原图，支持缩放、切换等功能，整个过程行如流水、丝丝顺滑！

图片文章及图片灯箱体验

本文部分功能需升级zibll子比主题V5.3及以上版本！

特色简介

本篇教程我们主要讲解图片灯箱功能，这个功能很简单，仅仅是点击图片即可，那么我们首先介绍一下子比主题的图片灯箱有哪些特点：

  • 两种模式可设置：单图模式和幻灯片模式
  • 支持缩略图导航功能
  • 支持下载原图功能
  • 支持自动播放功能
  • 支持双击放大、缩小
  • 支持下滑关闭
  • 支持移动端双指触摸放大、缩小
  • 支持键盘左右键切换图片
  • 采用硬件加速的动画引擎，整个切换、缩放过程丝丝顺滑
  • 未使用第三方JS插件，自行开发仅6KB大小文件
  • 对应的js文件动态按需加载
  • 灯箱内图片自动获取原图且异步加载，有效提高页面加载速度

选项配置

此功能建议保持默认即可，如需配置可以进入：
主题设置->文章&列表->文章功能：图片灯箱

配置项目十分简单，根据选项按需配置即可

那么我们简单的放几张图片供大家体验一下，记得要分别在PC端和移动端都体验喔！
