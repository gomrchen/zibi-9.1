zibll子比主题配置不同类型用户文件上传格式、上传大小限制教程[V7新功能]

来源：https://www.zibll.com/13972.html · 离线镜像

zibll子比主题更新V7.0以后，新增了用户上传文件的功能，用户可以直接在前台发布文章、发布帖子的时候上传并插入附件下载，更好的扩展了交互功能。同时也新增了前台设置付费下载功能，同样支持上传文件进行设置

提到上传文件，那么很重要的就是允许上传哪些格式的文件呢？又允许上传多大的文件呢？

zibll子比主题拥有强大的用户权限管理系统，借助这个系统，我们可以轻松的配置不同类型的用户允许上传不同的文件格式，接下来我们开始教程。

使用此功能需升级zibll子比主题V7及以上版本

教程准备

教程开始之前，如果您还未了解过子比用户权限管理系统，强烈建议您看一下以下教程

zibll子比主题用户权限管理系统简介及教程[V6新功能]

文件大小上传限制

进入主题设置->功能&权限->扩展权限：添加哪些用户，允许上传多大的文件

配置十分简单且清晰一目了然，需要注意的是：

设置上传大小，请考虑服务器负荷，以及服务器最大能支持的范围！上传文件最大大小，不能超过php.ini的配置。如果使用了cdn还需考虑cdn支持的最大上传大小！
同时上传大文件十分消耗服务器网络性能，文件越大越越占用带宽，当带宽不够或者服务器性能不足时候，则会出现上传失败的现象

上传格式限制

进入主题设置->功能&权限->扩展权限：添加哪些用户，允许或禁止上传的文件格式

注意事项：

  • WordPress已经默认允许了常用文件格式的上传，则无需再添加。如需禁止再禁止即可
  • 禁止的优先级大于允许
  • 请添加文件的扩展名和MIME类型，用英文逗号分割。格式示例：mp3=audio/mpeg,jpg=image/jpg
  • 郑重提示：请勿允许上传php、sh、exe等可执行文件，会极大的增加服务器被入侵攻击的风险
