文件上传，文件下载是一个wordpress网站常用的功能，zibll子比主题更新V7以后新增了文件上传管理以及文件下载模块的功能，可以很方便的通过古腾堡编辑器或者经典编辑器插入此模块，让用户更加直观的下载附件。

功能特色简介

  • 后台使用古腾堡编辑器的附件下载块
  • 前台使用此功能支持用户权限管理，可细分的设置哪些用户可以使用此功能
  • 支持上传文件、支持手动属于附件下载地址
  • 上传的本地文件自动隐藏真实下载地址，防止文件被刷
  • 支持与隐藏模块配合使用，实现评论可见、会员可见、付费可见
  • 同时支持文章和论坛帖子

使用教程

后台使用

后台我们直接使用古腾堡编辑器的附件下载块即可

如果您还未了解过强大的古腾堡编辑器，建议您查看以下教程：

Zibll子比主题-编辑器增强-古腾堡编辑器块详解[入门详解]
1年前
3.5W+128

古藤堡块额外支持单独配置文件图标，添加文件属性。

前台使用

用户在前台投稿或者在前台发布帖子使用此功能，支持用户权限管理，我们可以细分的设置哪些用户可以使用此功能。

如果您未了解过zibll子比主题强大的用户权限管理系统，强烈建议先查看此教程：

zibll子比主题用户权限管理系统简介及教程[V6新功能]
6个月前
2W+72

配置方法：

进入主题设置->功能&权限：分别配置投稿、发帖允许上传文件及插入附件下载的权限

然后务必配置好允许用户上传文件的大小和格式限制，具体教程请查看以下文章：

zibll子比主题配置不同类型用户文件上传格式、上传大小限制教程[V7新功能]
1年前
1.3W+59

全部配置完成后，拥有此功能权限的用户就可以在编辑器插入附件下载功能了

配合隐藏模块使用

当然此模块是可以配置隐藏模块使用的，无论是前台还是后台的古藤堡编辑器都是可以配合隐藏模块使用，实现付费可见、会员可见、评论可见。
