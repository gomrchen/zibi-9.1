通过微信公众号的模板消息功能，将网站消息推送给用户及管理员。我们来看看部分消息的截图预览

  • 新订单通知用户
  • 新订单通知管理员
  • 获得创作分成通知作者
  • 获得推荐佣金通知推荐人
  • 用户申请提现通知管理员
  • 提现处理后通知提现用户
  • 用户提交身份认证通知管理员
  • 身份认证处理后通知用户
  • 收到举报后通知管理员
  • 处理用户举报后通知举报人

  • 绑定或修改邮箱通知用户
  • 新评论通知文章作者
  • 评论有新回复通知用户

配置教程

配置教程主要分为三步

  1. 选择自己公众号的服务类目
  2. 搜索并找到合适的模板，按照主题设置对应的参数进行添加
  3. 将添加的模板ID，以及参数名称保存到主题配置

1.设置服务类目

首先就是第一步选择服务类目，现在新版本的模板消息，支持选择最多5个服务类目，我们根据自己网站的类型合理选择即可。

不同类目的模板是有区别的，但是也有很多类型相同的，只要能找到我们需要的模板消息类型就都可以的。主题的消息推送主要是订单类、用户管理等等，所以我们一般可以添加商业服务、文旅等类型的类目

进入公众号平台，点击账号详情-服务类目，添加合适的类目

因为一共可以设置5个类目，我们可以先添加1到2个，然后进入下一步查找合适的模板，如果没有找到合适的模板，我们还可以再次添加其他的类目。

2.查找合适的模板

这一步是最重要的，也是最繁琐的，没办法，现在微信对消息管理十分严格。

主要流程分为三步：

  • 确定要添加的消息名称，在主题设置中打开后，可以看到需要的参数名称
  • 根据要添加的消息名称，和需要的参数，通过搜索慢慢找到合适的模板
  • 将模板消息的ID和参数名key保存找主题配置中

假设我们现在需要添加新订单通知用户的模板消息，在主题设置中，我们看到有商品名称、金额、付款时间、订单号这四个参数

那么我们进入公众号-广告与服务-模板消息，在模板库-类目模板中，通过搜索，找到名称尽量类似新订单通知用户的的模板，然后点击详情，找到类似商品名称、金额、付款时间、订单号这四个参数，如果正好有，就添加这个四个参数，如果没有就继续查到其他的模板

这里需要注意两点：

  1. 不要选择(常量)的关键词，除非主题设置中明确标注了常量，选择常量记得把主题设置中标注的常量枚举进去。
  2. 公众号添加的参数关键词数量不能超过主题设置中的参数数量

完成添加后，回到我们模板中，就可以看到刚刚添加好的模板了，点击详情，将参数的英文key填到主题设置中。

注意：显示的{{thing9.DATA}}，只需要填thing9即可！注意看图：

ok，到这里我们就已经完成一个模板消息的配置了，那么我们举一反三用相同的方式添加其它模板消息即可。

提醒一下：主题可以添加的模板消息非常多，不建议全部都添加，仅添加符合自己网站常用的消息即可，因为在有限的5个类目中很难全部都找到合适的模板

还有就是整个过程最麻烦的其实就是找模板，这个繁琐还不一定能找到，这时候我们记住，只要消息标题和参数的语义大致差不多就行了，只要用户能读懂是什么意思就行了

关于参数，微信公众号添加的参数不能比主题设置中的少，但是如果没有找到合适的参数，可以少添加，主题设置中留空即可。另外选择参数时，尽量选择thing类型，有些类型可能会失败

最后，添加完成后，记得在主题配置最下方进行测试，如果推送失败，会显示错误原因
