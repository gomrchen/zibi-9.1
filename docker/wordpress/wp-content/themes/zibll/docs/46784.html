论坛付费板块、付费圈子功能详解及配置教程[V8.7新功能]

来源：https://www.zibll.com/46784.html · 离线镜像

使用WordPress搭建社区论坛或者私域、圈子、贴吧等类型的网站，很多站长都会有付费板块、付费圈子的需求，zibll子比主题支持完善的社区论坛系统，此次zibll子比主题V8.7新增了两个重要付费板块相关的功能，分别是：

  1. 新增板块发布权限和阅读权限都支持配置关注后允许，可实现例如：关注板块后才能查看、才能发帖，加入圈子后才能查看、发布等功能
  2. 新增自定义关注板块的关注名称命名，也就是修改“关注”这两个字，例如改为：加入、入驻、订阅等，更加适合将论坛作为圈子、社群等组织使用
  3. 新增付费关注的功能，用户需支付费用后才能关注，配合以上两个功能即可实现：付费板块、付费圈子等功能
重要通知：由于政策原因，官网下架了论坛功能演示，如需查看zibll主题论坛相关功能演示，请跳转到到：www.zibll.top

使用说明

这里有几个功能需要注意：1.它们是完全独立的功能！2.又是相互关联的功能

  • 板块、帖子、关注等这些命名都是可以自定义修改的，例如改为圈子、论坛、社区、贴吧等
  • 板块的发布权限和查看权限支持单独设置，例如关注后才能查看，但是会员才能发布。或者查看和发布都需要关注后才行
  • 付费关注是单独的功能，也可以设置无需付费就能关注。设置成付费关注，在配个关注后的权限，即可实现付费加入后才能查看或发布的效果

配置教程

根据上面的说明，我们的配置也主要分为三个步骤，十分简单：

1.命名配置

进入主题设置-社区&论坛-命名定义：即可按需修改命名

2.配置权限

我们在新建板块时候，或者修改板块时候都可以配置对应的权限，权限分为发布权限和阅读权限，支持分别配置。

我们将权限设置为关注后，即可实现关注板块后才能发帖或者关注后才能查看此板块内容的效果

3.设置付费关注

我们将权限设置为关注后，如果我们还需要用户付费才能关注，我们仅需要打开付费关注，并设置价格即可，支持设置积分或现金价格。设置价格后，关注板块时候就需要付费才能关注了！
