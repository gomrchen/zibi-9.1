前端投稿、发帖设置上传图片、上传视频功能教程

来源：https://www.zibll.com/4447.html · 离线镜像

众所周知，普通用户在前台发布文章和发布帖子使用的编辑器不是古藤堡编辑器，这主要的原因是因为权限问题，古藤堡编辑器拥有的功能十分强大，但同时使用的权限也很多。对于普通用户来说，很多权限是不能给到的！又特别是对于图片和视频的上传功能，图片和视频都是十分占用服务器资源的，大多数站长也希望此功能仅开放给部分用户！

zibll子比主题拥有强大的用户权限管理系统，通过用户权限管理系统可以细致化的设置哪些用户可以在投稿、发帖的时候允许上传图片、上传视频。

例如：我们仅允许会员才能上传视频，等级达到3级才能上传图片等等

重要通知：由于政策原因，官网下架了论坛功能演示，如需查看zibll主题论坛相关功能演示，请跳转到到：www.zibll.top

上传视频功能需主题版本V6.2及以上版本，上传图片功能需主题版本V6.1及以上版本

设置教程

我相信已经熟悉zibll子比用户权限管理系统的朋友们已经明白这个功能怎么开启了，如果还不明白权限管理系统，建议先看一下这一篇文章

zibll子比主题用户权限管理系统简介及教程[V6新功能]
6个月前
2W+72

进入主题设置->功能&权限：找到对应的权限根据需要开启即可

进入主题设置->扩展&增强：分别设置上传图片、上传视频的最大上传大小

设置方式十分简单，却又超级强大！设置完成后，拥有权限的用户就可以看到上传图片、上传视频的按钮啦

最后温馨提醒：上传图片、视频都是特别消耗服务器资源和性能的，特别是视频，十分占用内存。在上传的时候又特别占用带宽，甚至如果您的服务器带宽不够，还会出现上传失败的现象！
所以，此功能请根据自身服务器条件酌情开启！
