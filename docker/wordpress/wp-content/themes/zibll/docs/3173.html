统一权限设置

首先我们需要设置一个统一的默认权限方案，也就是哪种类型的用户允许发帖、创建板块

进入主题设置->功能&权限->论坛权限：找到创建板块和发布帖子，根据需求配置即可

您可以将权限细分的设置到每一个不同的用户组

单独设置权限

假设我们已经设置好了统一权限，大部分用户都可以创建板块和发帖。但是假设我们想实现以下功能：

  • 有一个系统公告的分区，我们希望这一个分区仅允许管理员以及分区版主才能创建板块，其它用户不能创建板块
  • 有一个会员专区的分区，这一个板块我们只允许会员才能创建板块
  • 有一个版务公告的板块，需要设置为仅允许管理员或者版主才能在此板块发帖
  • 有一个VIP交流的板块，需要设置为仅VIP会员才能在此板块发帖

那么我们就需要为分区或者板块单独设置权限！配置流程一共两步：

1.进入主题设置->社区&论坛->权限配置，先创建几个权限选项

我们在这里添加后选项，那么我们在创建板块分区或者创建板块的时候就可以进行选择了！

2.创建分区、板块的时候选择发布限制
