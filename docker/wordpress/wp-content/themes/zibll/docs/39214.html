zibll子比主题-商城首页创建及配置教程[V8.2新功能]

来源：https://www.zibll.com/39214.html · 离线镜像

zibll子比主题更新V8.2后，带来了全新的商城系统，支持销售所有类型的商品，现在我们可以使用WordPress和zibll主题就能轻松、快捷、低成本的搭建一个精美优雅的商城网站了。

此次更新我们抛弃了之前论坛系统使用页面模板的创建首页的方式，现在我们可以完全使用一个空白页面+模块化布局创建任何页面，当然用来创建商城首页也再合适不过了！

熟悉模块化布局

教程开始之前，我们需要先了解一下zibll子比主题强大的模块化布局功能，就像拼积木一样组合布局，简单方便且高度自由化！我们强烈建议先查看并熟悉以下教程：

页面布局、模块使用及可视化布局教程[网站布局入门教程]
3个月前
8.7W+98

创建页面并配置

教程开始，首先第一步就是创建一个空白页面，并做一些基础的必要配置：

  1. 先设置别名，也就是网址链接后缀，注意必须为唯一值，不能重复（如果你后面需要把此页面设置为整个网站首页，可以忽略此步骤）
  2. 将布局设置为无侧边栏，一般商城首页都是不需要的，如果你需要在侧边栏显示模块，也可以开启
  3. 因为我们仅使用模块化布局，所以需要关闭标题显示
  4. 同理，关闭内容显示
  5. 重要的来了！必须开启模块布局，并开启一个容器位置（因为没有开启侧边栏，所以除了侧边栏其他几个容器都是一样的）
  6. 有些商城首页顶部会显示视频或者幻灯片，看上去很大气，所以顶部多功能组件功能根据您的需要启用【查看教程】

添加模块

保存页面后，进入前台，点击模块配置，即可进入模块配置页面，在这里我们按需添加模块

作为商城首页，一把常用的模块有：幻灯片模块、图片模块、图文视频封面模块、还有最重要的商品列表模块等等

通过各种模块组合，我们很轻松的就可以做好我们的商场首页了

导入模块模板

子比主题 V8.9 更新了模块模板导入的功能，可以更加快速地创建商城首页。

选择模板导入后，就可以实现和官方演示站商城首页类似的效果。导入后，只需要把标题、图片按自己的需要进行修改即可。

设置为网站首页

有些网站主要以商场为主，文章、论坛只作为次要内容，我们就可以把刚刚创建的页面设置为网站首页，文章或论坛就可以作为商城的辅助信息平台了，例如淘宝社区、评测等等。

配置方法也十分简单，进入后台->设置->阅读：将主页设置为静态页面，并选择刚刚创建的页面

主题关联配置

创建好商城首页后，我们还需要将商城首页的链接配置到主题设置中，然后再根据需要配置商城的面包屑导航

举一反三

最后，大家一样要把思路打开，模块化布局是一个十分强大的功能，如果您略懂HTML，那将会有更好的效果和模块。同时以上教程我们仅仅是以创建网站首页为例，同时您还可以通过此方式创建任意的页面，或任意效果的首页。例如企业官网，炫酷的视频首页、技术服务说明页面等等
