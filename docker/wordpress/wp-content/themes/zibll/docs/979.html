Zibll子比主题-第三方登录-网站接入QQ登录图文教程

来源：https://www.zibll.com/979.html · 离线镜像

子比主题自带第三方社交帐号登录功能，QQ登录是非常常见的第三方登录，使用方便，申请比较简单，也不需要费用，但是需要你的域名已经备案。
本篇教程将详细的教你如何申请 QQ登录 以及设置子比主题！

提交申请

首先在QQ互联平台登录你的QQ, 注册成为QQ互联平台开发者

在右上角头像处点击进入授权管理

然后在应用管理->创建应用->创建网站应用

填写好相关资料->提交

接下来就是网站信息，需要准确的填写：
注意回调地址在：主题设置-社交登录-QQ登录 复制过去

接下来就是等待3-7个工作日的审核了，一般几个小时就审核了，看情况吧

获取ID和Key

审核通过之后，点击查看

先确保应用接口中的 登录 和 unionid 均已获取

然后记录 APP ID 和 APP Key

主题配置

进入Wordpress后台-主题设置-社交登录-QQ登录
开启QQ登陆
对应填入 APP ID 和 APP Key

保存之后就可以在前台登录界面看到QQ登录的按钮啦
主题接入的第三方登录非常多，根据你网站的接入数量，可以调整 主题设置-社交登录-最下方按钮样式，以达到最好的显示效果喔！
