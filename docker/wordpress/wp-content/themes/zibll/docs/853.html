隐藏内容功能：登录可见、付费可见、会员可见、评论可见、输入密码可见

来源：https://www.zibll.com/853.html · 离线镜像

在这个知识付费的年代，使用Wordpress建站的站长可以说非常需要这样的功能。将文章中的一部分内容隐藏，然后设置某种方式可阅读，例如：付费阅读、评论后查看、会员可见、登录可见或者关注公众号获取查看密码等效果。

在子比主题V3.1版本更新后，带来了全新的隐藏内容古腾堡模块，轻松就能实现上述功能。

支持的功能

  • 付费阅读可见
  • 登录可见
  • 评论回复可见
  • 一级会员可见
  • 二级会员可见
  • 输入密码可见(类似于关注公众号获取密码引流的功能)(V5.3版本新功能)

使用教程

使用十分简单，一共三步

  1. 选择 隐藏内容（新版）块
  2. 插入需要隐藏的内容，支持插入任意内容和其他模块
  3. 设置隐藏可见模式
