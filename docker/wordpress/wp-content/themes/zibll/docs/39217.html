zibll子比主题商品参数配置-配置继承功能详解及说明[V8.2新功能]

来源：https://www.zibll.com/39217.html · 离线镜像

zibll子比主题V8.2新增商城系统，在配置商品参数的时候，我们带来了全新的配置继承功能，让餐食配置时既简单易用又高度的自由化！

那么什么是参数继承呢？简单的说就是商品的某一个参数，我们可以为商品、商品分类、父分类、主题设置都进行配置。当系统查询此参数的时候，会先查询该商品的配置，如果该参数没有配置，就查询该商品的分类配置，如果改分类也没有配置，就同理依次查询父分类，最后查询主题配置中的参数。

参数继承示例

例如我们有一个商品名为苹果16，它的分类结构依次为：数码产品->手机->苹果

系统现在需要获取这个商品的运费，那么参数查询的流程为：

  1. 系统首先会查询苹果16这个商品的运费参数，如果有单独设置则返回，如果为默认则继续查询分类配置
  2. 继续查询分类苹果的分类参数，如果有单独设置则返回，如果为默认则继续查询父分类配置
  3. 继续查询分类手机的分类参数，如果有单独设置则返回，如果为默认则继续查询父分类配置
  4. 继续查询分类数码产品的分类参数，如果有单独设置则返回，如果为默认则继续主题配置中的设置
  5. 最后查询主题设置中的参数，返回参数数据

思维扩展
