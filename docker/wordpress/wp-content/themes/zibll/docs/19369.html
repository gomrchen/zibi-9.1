功能介绍

此插件主要用于数据库内容批量替换，例如以下场景：

  • 网站更换域名（网址），这个是最常用的
  • 网站使用了云储存，需要把老数据中的图片地址更换过来
  • 网站域名由http换为https（这个其实也是换域名）
  • 批量替换付费下载链接中部分内容（之前我记得蓝奏云就换了域名，让很多站长麻烦很久）

以上示例，仅仅是一些常用的场景，实际上这个工具的核心就是数据库内容批量替换，但是既然涉及到数据库，那么使用此插件，请务必阅读并熟知以下注意事项：

  1. 使用前，请务必备份整个数据库！免得你操作出错没有了后悔药
  2. 替换时，请勿输入很短的替换值，容易误修改
  3. 工具会自动分析数据库表，自动处理序列化数据，支持所有主题及插件！
  4. 此工具仅批量修改数据库内容，对修改后会导致的结果无法判断，如果您不清楚您的操作会带来什么结果，请谨慎操作

插件的几个特点说明一下

  • 支持所有主题和插件
  • 插件开箱即用，启用后只在插件替换页面加载内容，其它任何地方都没有加载任何内容，确保性能影响为0
  • 默认支持中文、英文两种语言

补充教程

关于网站换域名的技巧和流程，简单说一下

例如你之前的域名为 www.abcddd.com 现在想要换为 www.abc111.com，那么替换的时候，请输入https://www.abcddd.com 换为 https://www.abc111.com

千万不要输入abcddd换为 abc111，这样很容易误操作!

然后流程顺序很重要，不然换了之后就可能打不开网站了！流程如下：

  1. 先把新域名做好解析，并确认解析生效（使用终端ping命令进行测试）
  2. 在宝塔(或其它服务工具)把新域名添加到网站域名中，旧域名先不要删除，并确保新域名能访访问网站（还没有使用工具换域名，用新域名打开会有很多错误，只要能打开网站任意内容即可）【查看截图】
  3. 确保上一条没有问题了！再使用本文的工具在WP后台一键更换域名
  4. 如果新域名也是https，记得在服务器更新新域名的SSL证书
  5. 最后，记得刷新redis以及各种缓存！然后在宝塔(或其它服务工具)把旧的域名删除即可
