zibll子比主题V6用户身份认证功能介绍及使用教程[新功能]

来源：https://www.zibll.com/2956.html · 离线镜像

使用WordPress做个一个现代化的优质网站，与用户的交互功能必须的全面，zibll子比主题V6更新后带来了全新的用户身份认证功能。使用身份认证功能区分网站的优质用户，例如公司企业认证、优质行为认证等等。同时搭配子比主题V6全新的用户权限管理系统，可以更好的实现认证用户的特权功能，张显认证用户的身份特质！

对于站长来说，身份认证功能也可以有效的提高用户粘性，提升网站品质。接下来我们就一步一步的了解此功能的详细使用教程

此功能需要zibll子比主题V6及以上版本！

功能介绍

首先我们还是简单的讲解一下zibll子比主题用户身份认证的功能以及特点：

  • 操作简单，主题设置一键开启即可(默认开启)
  • 支持单独开启或者关闭申请通道
  • 支持自定义认证名称和简介
  • 支持用户在前台发起认证申请
  • 支持设置允许申请认证的用户条件
  • 支持管理员在后台手动设置用户的认证标识
  • 管理员后台一键审核
  • 支持认证申请、申请通过邮件及站内信通知

功能设置

此功能设置，就十分简单了。
进入主题设置->用户&功能->身份认证：开启此功能即可，同时根据需要设置申请介绍以及申请限制

前台发起认证申请

用户可以点击其它已认证用户的认证信息详细发起认证申请，也可以在用户中心->身份认证发起认证申请，或者查看自己的认证详情

满足条件的用户可以直接填写认证资料并提交认证申请，不满足条件的会有提示：

用户提交申请之后，管理员进入WordPress后台->用户->身份认证：进行审核

最会，管理员审核后会通过邮件和站内信的方式通知用户审核结果。审核批准的用户就成为了尊贵的官方认证用户啦

后台手动设置

除了用户申请，管理员审核之外呢，管理员还可以在后台手动的将某一个用户设置为认证用户
进入WordPress后台->用户：选择用户点击编辑

特权设置

既然已经是认证用户了，那么搭配V6全新的用户权限管理系统，就可以轻松的实现部分功能仅认证用户可使用

具体请查看：用户权限教程

页面设置

另外主题还自带一个身份认证的页面模板，如果您需要一个链接或者需要更加详细的介绍，那么你可以通过这个页面模板创建一个身份认证的页面。
创建一个新页面，设置好标题，写好内容，选择zibll身份认证页面模板即可
