zibll子比主题积分转账、余额转账功能介绍及配置详解[V7.4新功能]

来源：https://www.zibll.com/18579.html · 离线镜像

一个现代化的WordPress网站必须要有强大的用户资金管理系统，zibll主题不仅支持在线支付，还支持余额系统、积分系统，zibll子比主题更新V7.4版本后带来了积分转账、余额转账的功能，支持自定义开关，积分转账还支持用户权限管理，再一次丰富了积分和余额的玩法，增强了网站的互动性。

功能简介

此功能需升级zibll子比主题V7.4及以上版本

  • 积分、余额转账都支持自定义开关
  • 支持单独设置转账手续费
  • 支持设置转账说明
  • 漂亮的UI、丝滑的操作体验
  • 支持配置用户权限管理，可以细分的配置哪些用户可以使用此功能

配置教程

进入主题配置-付费商城-余额充值：开启余额转账功能，并配置手续费及说明

进入主题配置-用户功能-用户积分：开启积分转账功能，并配置手续费及说明

启用此功能后一定要记得配置用户权限，也就是配置哪些类型的功能可以使用此功能，如果您还不熟悉子比主题强大的用户权限管理系统，请先查看以下教程
