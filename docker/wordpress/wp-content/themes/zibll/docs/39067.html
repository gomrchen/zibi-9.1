zibll商城系统详解-知识付费、实物商城等功能入门教程

来源：https://www.zibll.com/39067.html · 离线镜像

zibll子比主题从21年开始就支持虚拟资源付费功能了，包含付费阅读、付费下载、付费视频、付费图库，配合付费VIP功能，让zibll主题成为了更多知识付费网站的热门WordPress主题模板。zibll子比主题更新V8.2后，又带来了全新的商城系统，这一次真正的让zibll子比主题成为最优雅、最完善的WordPress商城主题了！

功能简介

简单的介绍一下zibll主题的商城系统的功能和逻辑

首先，zibll子比主题商城商品主要分为3大类型：文章、帖子、商品

  • 发布文章时支持设置付费阅读、付费下载、付费视频、付费图库，这是知识付费网站常用的板块，例如教程收费网站、课程收费网站、软件下载网站、图片分享网站等等
  • 发布帖子时支持设置收费阅读帖子、支持隐藏部分内容付费查看，这是社区论坛、圈子等类型网站必备功能
  • V8.2新增的商城功能，直接发布商品，支持任意实物商品（例如手机、服饰等）、自动发货的虚拟商品（例如：卡密、自动发送文本等）、手动发货的虚拟商品（例如游戏币充值、软件定制等），几乎和我们目前熟知的淘宝、京东、拼多多的购物流程一致，这成为了独立商城网站的必要功能

其次，就是强大的辅助功能，例如推广返佣（推荐奖励、分销功能）、创作分成、站内余额、站内积分、VIP付费会员、优惠码、卡密兑换、站内消息等功能与商城系统紧密配合，实现各种个性化、高度自定义的丰富效果。

V8.2新增的商城功能又有更多的特点以及更强大的功能：

  • 商品发布：
    • 自动虚拟商品：卡密、邀请码、等任意文本内容自动发货
    • 手动发货虚拟商品：例如话费充值、游戏币充值、远程技术辅助等
    • 任意实物商品：支持物流发货、物流监控、运费配置等
    • 商品选项：不同商品规格不同价格，不同库存，不同图片等
    • 服务保障：自定义商品服务，例如7天无理由退货等服务
    • 价格类型：积分商品、现金商品
    • 商品参数：例如手机的像素、屏幕尺寸、电池容量等
    • 商品限购：按会员等级、是否认证分别设置限购数量
    • 推广返佣：支持设置按比例返佣、固定佣金，按会员等级单数设置等(V8.5)
    • 自定义用户必留信息：例如话费充值要求用户必留手机号等
    • 自定义售后服务：是否开启退款、退货、保价等
    • 还支持配置封面图像、封面视频，支持多级分类、支持商品标签等功能
  • 优惠活动：
    • 支持立减、折扣的优惠方式
    • 支持设置时间有效期，满多少金额可享受、哪些用户类型可享受
    • 赠品：支持添加多个赠品，支持赠送站内虚拟资源(积分、会员、经验值等)或其它任意商品
    • 优惠活动可叠加、可多选
  • 功能逻辑：
    • 用户下单，快捷支付
    • 加入购物车、合并支付
    • 虚拟商品自动发货，实物商品通知商家发货
    • 物流跟踪，用户确认收货
    • 用户评价
    • 申请售后、商家处理、退货或退款
  • 后台统计：
    • 重新设计了后台统计页面
    • 功能更加丰富、UI更加美观
  • 其它特色：
    • 配置极其简单：3分钟上手，后台配置清晰一目了然，配置逻辑简单易懂，不用看教程都会用
    • 功能强大且高度自由化：几乎商城需要的所有功能都有，并且我们首次采用配置继承功能，配置参数时高度自由化
    • 精心打磨的UI设计：不管是PC端还是移动端，所有细节都是精心打磨，大到整体框架，小到文字颜色、间距再到UI动画都是精心处理，就是让用户享受比淘宝京东还丝滑的购物体验
    • 优雅的的购物体验：用户的购物流程和现代化商城APP完全一致，简单易用，0上手成本
    • 高性能优化：V8.2新增了约20%的代码量，但是性能反而再次提升20%，降低建站成本和门槛【查看优化教程及说明】
