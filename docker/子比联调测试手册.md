## 0. 环境准备

```bash
cd docker && docker compose up -d
# 一键：缺口扫描 + CLI 冒烟 + admin-ajax 探测 + 商城未登录 curl
./scripts/zibll-run-all-checks.sh
```

报告可保存：`./scripts/zibll-run-all-checks.sh | tee 子比联调检查报告.txt`

自动会：开启 `shop_s` + `pay_balance_s`、创建 `zibll_probe_user`（余额 100）+ 自动发货商品、探测授权/更新/商城下单（余额支付）/论坛 AJAX。

可选 `wp-config` 常量（联调）：

| 常量 | 作用 |
|------|------|
| `ZIBLL_AUT_OFFLINE_OK` | 提交授权码时不校验远程 API |
| `ZIBLL_AUT_ALWAYS` | 强制已授权 |
| `ZIBLL_FORCE_NOT_LOCAL` | 本地也显示授权 UI |
| `ZIBLL_AUT_API_BASE` | 自建授权 API 根 URL |

## 1. 授权链（inc/code）

### 1.1 加载

`inc/inc.php` → `require.php` → `code|aut|file|tool|update` + `zib-update.php`。

| 检查项 | 预期 |
|--------|------|
| 前台 `localhost` | `ZibAut::is_local()` true，不 `wp_die` |
| 非本地且未授权（可 `ZIBLL_FORCE_NOT_LOCAL`） | 前台 503 文案 |

### 1.2 AJAX `admin_curl_aut`

| 项 | 内容 |
|----|------|
| 权限 | `manage_options` |
| POST | `action=admin_curl_aut`，`aut_code`（必填） |
| 处理 | `ZibAut::save_aut_code` → `ZibAut::curl_aut` |
| 成功 JSON | `error:false`, `msg`, `reload:true` |
| 失败 | 空码 / 远程失败 / 无权限 |

**手工**：后台 → 主题设置 → 授权区域 → 输入码 → 立即授权；Network 看 `admin-ajax.php`。

### 1.3 AJAX `admin_delete_aut`

| POST | `action=admin_delete_aut`（无 body 要求） |
| 处理 | `ZibAut::delete()` 清 `zibll_code` 等 option |

### 1.4 方法抽查（CLI 或 `var_dump`）

| 方法 | 参数 | 返回 |
|------|------|------|
| `ZibAut::curl_aut_data` | `$aut_code=''` | `code,domain,home,version,sign` |
| `ZibAut::get_aut_code_sign` | `$aut_code` | 64 位 hex |
| `ZibCodeAut::is_token` | `$data` array | 无 sign 时 true；有 sign 时 `hash_equals` |
| `ZibCodeAut::update` | `$time_int, $payload` | int；`aut_time_int` 过滤器 |

## 2. 更新链（CSF + inc/code + zib-update）

### 2.1 检测 / 忽略

| action | POST | 处理 |
|--------|------|------|
| `admin_detect_update` | 仅 action | `ZibAut::curl_update(true)` → JSON `reload:true` |
| `admin_skip_update` | 仅 action | 写 `zibll_skip_update_version` |

### 2.2 在线更新三步

| 步 | action | 明文联调预期 |
|----|--------|----------------|
| 1 | `zibll_online_update` | `ZibCodeUpdeta::online_update()` → `error:true` + 文案 |
| 2 | `zibll_download_update` | `download_update()` 同上 |
| 3 | `zibll_update_file` | `update_file()` 同上 |

**手工**：主题设置 → 文档&更新 → 在线更新；看 CSF `main.js` 是否链式带 `n.action`。

### 2.3 `ZibCodeUpdeta::check_url_data`

| 参数 | `$rand_int`, `$data` array |
| 逻辑 | `ZibCodeAut::zib_get_admin_require_intdata` + `is_token` |

## 6. 失败时排查

1. `docker exec wp-app tail -50 /var/www/html/wp-content/debug.log`
2. 确认 `action` 在清单 §1 已注册（冒烟脚本 `registered wp_ajax_*`）
3. 403/0：未登录或 nonce；授权接口需管理员 cookie
