# 子比加密 ↔ 明文深度对照（联调）

## 1. 对照范围

| 密文备份 | 明文路径 |
|----------|----------|
| `inc/code/.encrypted-bak/*`（8） | `inc/code/*` + `inc/class/db-class-legacy.php` |
| `.encrypted-bak-rest/*`（6） | 同路径下对应 `.php` |

**说明**：`inc/code/.encrypted-bak/require.php` / `new_aut.php` 的 strings 中含兄弟项目「免授权改造」注释，说明该备份曾混入改造稿；**官方 Z5 行为以 VM 内逻辑为准**，本仓库以 `inc/code/require.php` 全量加载链 + 可配置 `ZibAut` 为联调基准。

## 2. 加载链（明文）

```
inc/inc.php
  → inc/code/require.php
      code.php → aut.php → file.php → tool.php → update.php → inc/options/zib-update.php
      zib_admin_tool_action()
```

历史路径：`inc/code/action.php` → `aut.php`；`inc/code/new_aut.php` → `require.php`。

## 3. 深度契约（非 strings 可扫）

| 点 | 密文意图 | 明文实现 |
|----|----------|----------|
| `aut_time_int` | `ZibCodeAut::update` 作过滤器，2 参数 | `update($time_int, $payload)` + `add_filter(..., 10, 2)` |
| `setup_data_randstr` | 在 `aut.php` 注册 | `aut.php` 注册 + `zibpay_admin_page_aut_randstr` 兜底定义 |
| `ZibDB::is_exists` | 链式存在判断 | `db-class-legacy.php` `is_exists()` → `count()>0` |
| `zib_shop_get_url_chick_data` | 商城支付域名校验数据 | 返回 `domain/home/code/sign/version`（`ZibAut`） |
| `zib_shop_setup::setup` | 构造后 `aut/tool/ajax` | `setup()` 开头调用三方法（联调空实现） |
| 前台未授权 | 原 VM 可能 `md5_file` + `wp_die` | `zib_init_add_action`：`aut_required` + 非后台 `wp_die(503)` |
| 在线更新多步 AJAX | `zibll_online_update` → `zibll_download_update` → `zibll_update_file` | 三步均已 `add_action`；联调返回「未启用远程」JSON |

## 4. 仍无法在静态还原的部分

- Z5 VM 内 `admin_manage` / `ajax_posts`（BBS）、`zib_shop_setup::ajax()` 的具体 `wp_ajax`：主题已在 `bbs/action/*.php` 明文实现，类内保持 no-op。
- `ZibAut::admin_js` / `footer_html`：官方为授权 UI 脚本；联调为空，CSF 授权 UI 主要靠 `options-module.php`。
- 真实远程授权 / 更包：需 `ZIBLL_AUT_API_BASE` 或官方 API，默认联调不拉包。
